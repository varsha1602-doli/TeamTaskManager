## 2. Product Vision

TaskForge is a modern full-stack team collaboration platform designed to help organizations efficiently manage projects, assign tasks, monitor team productivity, and track progress in real time using secure role-based access control.

The platform combines:
- Project management
- Team collaboration
- Smart dashboards
- Task tracking
- Secure authentication
- Enterprise-level architecture

into one scalable application.

## 3. Problem Statement

Small teams and startups often struggle with:
- Unorganized task management
- Lack of visibility into project progress
- Poor team coordination
- No centralized workflow system
- Difficulty tracking overdue tasks
- Inefficient role management

Existing solutions are either:
- Too complex
- Too expensive
- Overloaded with unnecessary features

TaskForge solves this by providing a lightweight yet powerful project collaboration system with an intuitive UI and efficient workflow management.

## 8. REST API Design

### Authentication APIs
POST /api/auth/register
POST /api/auth/login
GET /api/auth/me

### Project APIs
GET /api/projects
POST /api/projects
GET /api/projects/:id
PUT /api/projects/:id
DELETE /api/projects/:id

### Task APIs
GET /api/tasks
POST /api/tasks
PUT /api/tasks/:id
DELETE /api/tasks/:id

### Team APIs
POST /api/projects/:id/members
DELETE /api/projects/:id/members/:userId

### Dashboard APIs
GET /api/dashboard/admin
GET /api/dashboard/member
